Coders Cafe Management System

About the Project

This is a simple Cafe Management System created using Python. It allows customers to select food items, place orders, and calculate their total bill.

🍔 Menu

- Pizza – ₹100
- Salad – ₹50
- Burger – ₹130
- Pop Corn – ₹150
- Chicken Puff – ₹80

✨ Features

- Display cafe menu
- Take customer orders
- Check item availability
- Order multiple items
- Calculate total bill
- Display ordered items

🛠️ Technologies Used

- Python 3
- VS Code

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

python main.py

📚 Python Concepts Used

- Dictionaries
- Lists
- While loops
- For loops
- If-else conditions
- User input
- Functions like "lower()", "strip()" and "append()"
